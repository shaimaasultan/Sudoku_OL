🧩 Rubik Sudoku

Solve by systematic moves from the home grid · S. S. Soltan
Varied puzzles can't be solved by Rubik moves — try Colour mode.

Moves from the home grid

Tiles start as your home grid (r·b + ⌊r/a⌋ + c) mod N + 1. Each move keeps every row, column and box valid — like turning a Rubik's cube. White corner numbers are the puzzle's givens.

🎨 Colour mode — the anti-Rubik solve

Numbers become colours. Every puzzle starts from the same home grid (each box already holds one of each colour). Givens are pinned, logic pins what it can prove, then colours are swapped inside boxes until no row or column repeats a colour — the opposite of a Rubik's cube, where each face ends up one colour.

The systematic move method

  1. Start from the home grid. Row 1 is 1…N; each next row shifts by the box width, and each new band shifts by one more.
  2. Turn the cube? (square boxes only) Decide whether rows and columns are exchanged.
  3. Order the bands and the rows inside each band. Try the band for slot 1 and the order of its rows; keep it only if the givens it touches can still be matched with one consistent renaming of the numbers.
  4. Order the stacks and the columns inside each stack the same way, one slot at a time, alternating with the bands. A wrong choice is thrown away as soon as two givens disagree.
  5. Rename the numbers. Each given tells you which home number becomes which puzzle number (like repainting the colours of a Rubik's cube). Do it as number swaps.
  6. Done. The moved and renamed home grid is the solution. For a puzzle with one solution it must be the answer.

🎯 Step by step uses the same language like a Rubik's cube solver: bring one given to its cell at a time, trying every combination of up to 3 moves (swap 2 rows or columns, swap 3 rows with 3 rows or 3 columns with 3 columns, rotate 3 rows or columns, turn, swap numbers) and keeping the shortest one that doesn't undo a given already placed.

Why not every puzzle? These moves never leave the "family" of the home grid. Sudoku has about 5.47 billion essentially different solutions, so a puzzle whose solution comes from another family has no move sequence — solve it with the layer or cube method in the game instead.
