🏁 Few Givens Race

9×9, 12×12 or 16×16, from one given per number up to 80% filled — Dancing Links, MRV and lean option layers timed on the same puzzles · S. S. Soltan

Set up

Each puzzle is a random full grid of the chosen size with some cells kept: either one cell for each number (N givens on an N×N board: one 1, one 2, …) or the chosen share of cells. A 9×9 Sudoku needs at least 17 givens to have only one answer, so with few givens there are many answers: each method stops at the first valid grid it finds, and an answer counts as correct when every row, column and box holds 1–9 once and every given is kept. Random cells give many answers far above 17 givens too: in a test of 100 9×9 puzzles per fill, none had one answer at 30% or 34%, 5 at 40%, 40 at 50%, 75 at 60% and 87 at 70%. A typical 34% puzzle has about 175 answers (from 2 to about 10,000). (The Speed page's hard puzzles are different: givens are removed only while exactly one answer remains.) Short solves are repeated and averaged. With few givens every number layer has thousands of options; a small option cap makes lean wait for the cuts (or guess on a cell) instead of listing them all — Lean OL · Speed page (as is) is the Speed page's lean method unchanged — same code and same settings (top 2 layers, fewest open cells first, cap 300,000); the lean menus on this page change only the other leans. Lean OL · dynamic cap starts with the cap from the menu and, as the board fills, builds a too-big layer in full once its size bound (open cells per box, multiplied) shows that its whole list fits in 300,000 options. Run every fill runs all the fills above in turn and draws the line graph.

    Results

    Valid = a full grid with 1–9 once in every row, column and box that keeps every given. Guesses / nodes: Dancing Links and MRV count search nodes (every node is a trial). The lean methods keep no counts at all (–): they only solve.

    Times when the answers are the same

    For each pair of methods, the puzzles are split into those where both returned exactly the same grid and those where they returned different grids. Median times are shown for each group, so the times in the "same answer" columns compare the two methods on identical results.

    Do the methods find the same answer?

    Each cell of the table: on how many puzzles the two methods returned exactly the same grid. When a puzzle has many answers, each method stops at the first one it reaches, so two methods can give two different valid answers.
