The chips are the units — rows (R) and columns (C) — with the number of options each still has (– = not built yet, ✓ = locked). The unit being worked on is outlined on the board; its cells are shaded by the share of its options that put a queen there.

How it works — the same method as your Sudoku layers

  1. Units: every row and every column must hold exactly one queen, and no two queens may attack each other — not in the same row, column or diagonal. A unit here is like a number's layer in Sudoku; each cell is shared by one row and one column, like a pillar, and the diagonals work like the Sudoku box: a queen blocks them.
  2. Givens: a few queens are already placed (dark) so that exactly one solution is left.
  3. Option layers of a unit: every free cell where its queen can still go.
  4. Thinnest units first: start with the 2 units that have the fewest options; when the cuts stop, open the next thinnest unit.
  5. Cut options that use a cell already known to be empty.
  6. AND: if a unit has one cell left, the queen goes there and every cell it attacks becomes empty; a cell in no option is empty.
  7. 🔒 Lock a unit when one option is left.
  8. All units together: if every unit is built and the cuts stop, test each option of the unlocked units on its own — if assuming it makes some unit lose all its options, it is cut. Nothing is guessed.
  9. Only if even that stops: guess and go back if it fails.
