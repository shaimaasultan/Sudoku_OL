⚡ Option Layers — Speed

Only build the layers, AND and cut — how fast is it? · S. S. Soltan

The lean method

1 · BuildStart with only the top 2 or 3 numbers (fewest open cells, or most repeated) and list their options — never all layers at once.
2 · CutRemove options that use a cell the number can no longer take.
3 · ANDA cell in every option is certain; a cell in no option is removed. One option left = locked.
PillarA cell that only one number can still reach gets that number.

Repeat 2–3 while anything changes; only when stuck, add the next layer by the same rule. Guess (fewest options first) only when every layer is built and nothing changes. Left out on purpose: the step-by-step words and explanations — not just unprinted: nothing about the steps is recorded or counted (no rule per cell, no layer order, no counts of options or guesses) — the pair check, the 3/4-number group check and the probe. The data is packed in bit sets so every cut and AND is a few machine words.

Set up

All puzzles are made first (each has exactly one solution), then every method solves the same puzzles one after another. Short solves are repeated and averaged, so times below 0.1 ms are still measured. Every answer is checked against the true solution. Run all sizes tests 4×4, 6×6, 9×9, 12×12, 16×16, 20×20 and 30×30 at the chosen level (at most 30 puzzles for 12×12, 10 for 16×16 and 20×20, 5 for 30×30) and draws the line graph. On 16×16 and bigger, removing givens stops near half the cells (about 43% at 16×16, 48% at 20×20, 53% at 30×30), because proving that each puzzle still has one answer gets too slow; so Medium and Hard give the same puzzles there.
