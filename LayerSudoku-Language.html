The language

🧩 Global words — move whole lines; the grid stays a valid Sudoku
R1↔R3 · C4↔C6Swap two rows (same band) or two columns (same stack)
B1↔B3 · S1↔S2Swap bands (3 rows with 3 rows) or stacks
R1→R2→R3Rotate rows / columns / bands / stacks one place
TTurn: rows ⇄ columns
3⇄7Swap two numbers everywhere
🎨 Local words — change one place; can reach every family
3⇄7 b4Swap 3 and 7 inside box 4 only
3⇄7 r2Swap 3 and 7 inside row 2 only
3⇄7 c5Swap 3 and 7 inside column 5 only
3⇄7 r2c5The 3 at row 2, column 5 becomes 7: swap in row 2 and column 5
  1. Home grid — the same start for every puzzle: (r·b + ⌊r/a⌋ + c) mod N + 1.
  2. Global words move and rename whole lines to match as many givens as possible. A Classic puzzle is solved right here.
  3. Pin the givens (white) and, with Logic first, every cell logic can prove (dark) — using local swaps, so nothing else moves.
  4. Local words swap numbers in one place at a time until no row, column or box repeats a number. A swap that makes things worse is sometimes kept, to escape dead ends.
