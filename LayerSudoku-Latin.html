How it works — your Sudoku layers without boxes

  1. A Latin square is a Sudoku with no boxes: every number once in every row and every column. Some numbers are given so that exactly one solution is left.
  2. Number layers, exactly as in your method: every way to put a number once in each row and each column, avoiding cells already taken. Each cell is where the layers meet — like a pillar — and keeps the numbers every layer still allows.
  3. Most repeated / thinnest first: start with the 2 numbers that have the fewest options; open the next thinnest when the cuts stop.
  4. Cut options that use a cell another number has taken. Narrow: a number no option puts in a cell leaves that cell. AND: a cell used by all options of a number gets that number.
  5. Singles: a cell with one candidate left, or a number with one place left in a row or column, is placed.
  6. 🔒 Lock a number when one option is left — it is never visited again.
  7. All layers together: when the cuts stop, test each option of the unlocked numbers on its own — if assuming it breaks another number, it is cut. Nothing is guessed.
  8. Only if even that stops: guess and go back if it fails.
