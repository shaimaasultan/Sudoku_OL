How it works — the same method as your Sudoku layers

  1. Option layers of a line: every way to place the line's blocks (in order, at least one gap between them) that fits the cells known so far. A line here is like a number's layer in Sudoku; a cell is where a row and a column meet, like a pillar.
  2. Thinnest lines first: start with the 2 lines that have the fewest options; when the cuts stop, open the next thinnest line.
  3. Cut options that disagree with a cell already known from a crossing line.
  4. AND: a cell filled in all options of a line is filled; a cell empty in all of them is empty.
  5. 🔒 Lock a line when one option is left — every cell of it is known and its list is dropped.
  6. All lines together: if every line is built and the cuts stop, test each option of the unlocked lines on its own — if assuming it makes some line lose all its options, it is cut. Nothing is guessed: each option is checked and put back.
  7. Only if even that stops: guess an option of the line with the fewest options and go back if it fails.
