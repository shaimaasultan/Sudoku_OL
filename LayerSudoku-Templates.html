How it works

  1. Start small: build the option layers of the 2 (or 3) most repeated numbers only — they have the fewest options. An option layer is one cell in each box, no repeats in rows or columns, covering the number's givens and avoiding cells already taken.
  2. When the lists stop shrinking, add the next most repeated number. Numbers locked earlier have already taken their cells, so its list is built much shorter.
  3. AND each number's options: a cell in all of them is certain for that number.
  4. Cut options that take a cell certain for another number, and options that clash with every option of some other number (they can never sit together).
  5. Every cell needs a number: if only one number can still reach a cell, keep only the options of that number that cover it.
  6. 🔒 Lock a number when one option is left — confidence 100%. Its list is dropped and it is never visited again. Every cut is proven, so locked numbers never need a go-back.
  7. View: cube (slices) shows the same steps in the cube: rows × columns × numbers, one horizontal slice per number. An option layer lives inside its slice; the vertical pillars (one per cell) link the slices — when a slice locks, its pillars are full and every other slice loses the options that used them.
  8. Three, then four numbers together: when every number is built and the pair check is stuck, check the unlocked numbers 3 at a time — an option is kept only if every 2 other numbers still have options that fit beside it with no cell shared — then 4 at a time. Locked numbers are not in it; their cells are simply taken.
  9. Only if the lists stop shrinking: guess on the number with the fewest options left, trying first the option that clashes least with the other numbers' options. A wrong guess is undone and the next option is tried.
