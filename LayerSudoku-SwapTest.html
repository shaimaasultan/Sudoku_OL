🔬 Swap Test

Does it help to keep swapping even if it breaks what's already done? · Home-grid line moves · S. S. Soltan

The question

Every run starts from the same static home grid and uses the move language: swap 2 rows/columns, swap bands/stacks (3 rows with 3 rows), rotate 3 rows/columns, turn; numbers are renamed to fit (renaming isn't counted as a move). Three strategies race on the same puzzles:

Keep placed — never break a given already in place Break allowed — take any combination that raises the total Break + risk — also accept some worse moves to escape dead ends

Answer

Averages

Givens matched = givens showing their number after the best renaming. Cells correct = cells (of all N×N) equal to the true solution. Moves = line moves made (renaming not counted).

Every puzzle

🔬 Test 2 · Local swap words

Swap two numbers in one place only, instead of everywhere · from the static home grid

The words

Start from the home grid, pin the givens (and, with Logic first, every cell logic can prove), then keep using one word until no row, column or box repeats a number. Swaps that make things worse are sometimes kept, to escape dead ends.

3⇄7 in box k — Colour mode (boxes always stay valid) 3⇄7 in row i — rows always stay valid 3⇄7 in column j — columns always stay valid 3⇄7 in row i + column j — your cross word: the 3 at (i,j) becomes 7, and row i and column j each stay valid

Answer

Results

Tries = swaps attempted (for the cross word, attempts that would move a pinned cell count too). Time = computing time on this device. Repeats left = repeated numbers still in rows, columns and boxes when the try limit ran out (0 = solved).
