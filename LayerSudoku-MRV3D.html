How MRV works

  1. Pick the tightest cell. Look at every empty cell and count the numbers it can still take (not already in its row, column or box). Pick the cell with the fewest — the minimum remaining values. In the cube this cell is a pillar through all the number slices; its possible numbers are the big dots on the pillar.
  2. Try its numbers, smallest first. Put the number in the cell (a block appears in that number's slice) and go on to the next tightest cell.
  3. Dead end. If some empty cell has no number left, the last choices were wrong: the pillar turns red.
  4. Go back. Take the last number out (red block) and try the next number in that cell; if none is left, go back one more cell.
  5. Stop when every cell is filled. MRV proves nothing in advance — it tries, and backs up when a try fails.

This is the same MRV used on the Speed and Few Givens pages (same cell choice, numbers tried smallest first), here recording each step so it can be replayed. A puzzle with one answer makes MRV go back when an early try was wrong; a random 34% puzzle has many answers, so almost every try works.
