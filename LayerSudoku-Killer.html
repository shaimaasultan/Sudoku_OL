⚡ Speed test — lean option layers

The lean method keeps only the core: build the 2 (or 3) thinnest layers first — number layers or cages, whichever have the fewest options — cut options a cell no longer allows, AND (a cell in every option of a number layer gets it; a number no option puts in a cell leaves it; one option left = locked) and the pillar rule (a cell with one number left gets it). It adds the next thinnest layer only when stuck — a layer with more than 1,000 options waits until the cuts shrink it — and guesses last. Left out: the step log, the row/column/box singles and the "all layers together" probe.

The test makes new puzzles of the size chosen above (each with one solution), then times the three methods on the same puzzles. Short solves are repeated and averaged. Every answer is checked against the true solution.

How it works — your Sudoku layers plus cage layers

  1. Two kinds of layers. Number layers as in your Sudoku method: every way to put a number once in each row, column and box. Cage layers: every way to fill a cage with different numbers that add up to its sum. Each cell is where the layers meet — like a pillar — and keeps the numbers (candidates) that every layer still allows.
  2. Thinnest layers first: start with the 2 layers that have the fewest options — usually small cages — and open the next thinnest when the cuts stop.
  3. Cut options that use a number a cell no longer allows.
  4. Narrow: a number that no option of a layer puts in a cell is removed from that cell. AND: a cell used by all options of a number layer gets that number.
  5. Singles: a cell with one candidate left, or a number with one place left in a row, column or box, is placed.
  6. 🔒 Lock a layer when one option is left — its numbers are placed and its list is dropped.
  7. All layers together: when the cuts stop, test each option of the unlocked layers on its own — if assuming it breaks another layer, it is cut. Nothing is guessed.
  8. Only if even that stops: guess and go back if it fails.
