How it works — your layers on a map

  1. Like Star Battle: the map's regions are the units, and a border between two regions is where they meet — like a pillar. In Star Battle, stars in touching cells clash; here, the same color in touching regions clashes.
  2. Option layers of a region: the colors it can still take. Coloring a region removes that color from every neighbour (like a Sudoku number leaving its row, column and box).
  3. Thinnest region first: a region with one color left gets it (a single).
  4. Group check: three regions that all touch each other need three different colors — if their colors left add up to fewer, it is impossible; if two of them are left with the same two colors, the third can't use either.
  5. All regions together: when the cuts stop, try each color of a region on its own — if it leads straight to a region with no color left, that color is cut. Nothing is guessed.
  6. Only then guess (trying colors already used before a new one — colors can be swapped, so a new color is only tried once) and go back if it fails.
  7. Givens (optional): some regions start with their color (number in a dark circle). They come from a best coloring, so the fewest number of colors stays the same.
  8. The solve as words: every step is written as a word — S12=3, P7≠1,3, A3≠4, G5=2, ↩5 — using the region numbers on the map and the color numbers on the palette, so the language can be read against the map. At the end the solution is listed region by region.
  9. 🔢 Count solutions counts every coloring that works for this map (with its givens), out of all the ways to paint it — the working ones are a tiny share. Each count has a time limit; if it runs out, the page says "at least".
  10. Fewest colors: the biggest group of regions that all touch each other needs that many colors (lower bound); a quick greedy coloring gives an upper bound. The method tries k colors from the lower bound up — the first k that works is the fewest, and every smaller k has been proved impossible. On a flat map the answer is never more than 4 (the Four Color Theorem).
